## 修改步骤

### 步骤 1: 备份原始文件

在修改前，建议备份相关文件：

```bash
# 创建备份目录
mkdir -p backup/web-public-logo
mkdir -p backup/web-i18n

# 备份 Logo 文件
cp -r web/public/logo/ backup/web-public-logo/
cp web/public/favicon.ico backup/web-public-logo/
cp web/public/apple-touch-icon.png backup/web-public-logo/

# 备份语言文件
cp web/i18n/zh-Hans/dataset.ts backup/web-i18n/
cp web/i18n/en-US/dataset.ts backup/web-i18n/
cp web/public/manifest.json backup/web-i18n/
```

### 步骤 2: 修改 Logo 和图标

1. **准备你的 Logo 文件**
   - 推荐使用 SVG 格式以获得最佳效果
   - 确保在不同背景下都清晰可见
   - 提供浅色和深色两个版本（如果需要）

2. **替换文件**
   ```bash
   # 替换主要 Logo
   cp your-logo.svg web/public/logo.svg
   cp your-logo-light.png web/public/logo-site.png
   cp your-logo-dark.png web/public/logo-site-dark.png

   # 替换图标
   cp your-favicon.ico web/public/favicon.ico
   cp your-apple-icon.png web/public/apple-touch-icon.png
   ```

### 步骤 3: 修改文字内容

1. **修改知识库页面文字**

   编辑 `web/i18n/zh-Hans/dataset.ts`：
   ```typescript
   didYouKnow: '你知道吗？',  // 修改这里的文字
   intro1: '知识库可以被集成到您的应用中',  // 自定义介绍文字
   intro2: '作为上下文',
   intro3: ',',
   intro4: '或可以',
   intro5: '发布',
   intro6: '为独立的服务',
   ```

2. **修改英文版本**

   编辑 `web/i18n/en-US/dataset.ts`：
   ```typescript
   didYouKnow: 'Did you know?',  // 修改英文版本
   intro1: 'The Knowledge can be integrated into your application ',
   intro2: 'as a context',
   intro3: ',',
   intro4: 'or it ',
   intro5: 'can be published',
   intro6: ' as an independent service.',
   ```

### 步骤 4: 修改应用信息

编辑 `web/public/manifest.json`：

```json
{
  "name": "你的应用名称",
  "short_name": "简称",
  "description": "你的应用描述",
  "theme_color": "#你的主题色"
}
```

编辑 `web/app/layout.tsx`：

```typescript
// 修改这些行
<meta name="apple-mobile-web-app-title" content="你的应用名称" />
<meta name="theme-color" content="#你的主题色" />
<meta name="msapplication-TileColor" content="#你的主题色" />
```

## 详细修改指南

### 自定义品牌颜色

1. **主题色修改**
   - 在 `web/app/layout.tsx` 中修改主题色
   - 在 `web/public/manifest.json` 中更新颜色值

2. **CSS 变量**（高级）

   如果需要更深层次的颜色定制，可以修改 `web/styles/globals.css` 中的 CSS 变量。

### 自定义其他页面文字

1. **导航菜单文字**
   - 位置：`web/i18n/zh-Hans/common.ts`
   - 修改 `menu` 相关的翻译键值

2. **按钮和提示文字**
   - 查找对应的模块文件（如 `app.ts`, `dataset.ts` 等）
   - 修改相应的翻译内容

### 移除或修改功能提示

如果你想要移除知识库页面的"你知道吗"提示框：

1. **完全移除**

   编辑 `web/app/components/datasets/list/dataset-footer/index.tsx`：
   ```tsx
   const DatasetFooter = () => {
     const { t } = useTranslation()

     return (
       <footer className='shrink-0 px-12 py-6'>
         {/* 删除或注释掉这部分内容 */}
         {/* <h3 className='text-gradient text-xl font-semibold leading-tight'>{t('dataset.didYouKnow')}</h3>
         <p className='mt-1 text-sm font-normal leading-tight text-text-secondary'>
           {t('dataset.intro1')}<span className='inline-flex items-center gap-1 text-text-accent'>{t('dataset.intro2')}</span>{t('dataset.intro3')}<br />
           {t('dataset.intro4')}<span className='inline-flex items-center gap-1 text-text-accent'>{t('dataset.intro5')}</span>{t('dataset.intro6')}
         </p> */}
       </footer>
     )
   }
   ```

2. **替换为自定义内容**

   同样在上述文件中，替换为你的自定义内容：
   ```tsx
   const DatasetFooter = () => {
     return (
       <footer className='shrink-0 px-12 py-6'>
         <h3 className='text-gradient text-xl font-semibold leading-tight'>你的自定义标题</h3>
         <p className='mt-1 text-sm font-normal leading-tight text-text-secondary'>
           你的自定义描述内容
         </p>
       </footer>
     )
   }
   ```

## 部署流程

### 1. 前端构建

```bash
cd web

# 安装依赖（如果需要）
pnpm install

# 构建生产版本
pnpm build

# 检查构建结果
ls -la .next/
```

### 2. 验证修改

```bash
# 启动开发服务器验证修改
cd web
pnpm dev

# 在浏览器中访问 http://localhost:3000
# 检查所有修改是否生效
```

### 3. 完整部署

```bash
# 方法 1: 使用 Docker Compose
cd docker
docker-compose up -d --build

# 方法 2: 手动部署
# 先构建前端
cd web && pnpm build

# 再构建后端
cd ../api && make build

# 启动服务
```

### 4. 生产环境验证

1. **检查 Logo 显示**
   - 浏览器标签页
   - 移动设备主屏幕
   - 应用内各位置

2. **检查文字修改**
   - 知识库页面提示文字
   - 应用标题
   - 各种提示信息

3. **测试多语言**
   - 切换语言环境
   - 确保英文版本也正确显示

## 注意事项

### 🚨 重要提醒

1. **保持多语言一致性**
   - 如果修改了中文内容，务必同时修改英文版本
   - 考虑其他语言用户的体验

2. **测试兼容性**
   - 在不同浏览器中测试
   - 在移动设备上测试
   - 测试不同屏幕尺寸

3. **备份原文件**
   - 修改前一定要备份
   - 使用版本控制记录修改

4. **遵循设计规范**
   - 保持 Logo 的清晰度
   - 确保颜色对比度符合无障碍标准

### ⚠️ 常见陷阱

1. **Logo 格式问题**
   - 不要使用低分辨率的图片
   - SVG 格式适合矢量图标
   - ICO 格式适合 favicon

2. **缓存问题**
   - 修改后可能需要清除浏览器缓存
   - 强制刷新：Ctrl+F5 或 Cmd+Shift+R

3. **构建失败**
   - 检查 TypeScript 语法
   - 确保文件路径正确
   - 查看构建错误日志

### 🔧 最佳实践

1. **渐进式修改**
   - 先修改一个部分，测试后再继续
   - 不要一次性修改太多内容

2. **版本控制**
   ```bash
   git add .
   git commit -m "自定义界面：修改 Logo 和知识库文字"
   git tag v1.0-custom
   ```

3. **文档记录**
   - 记录所有修改的内容
   - 记录修改的原因和效果

## 常见问题

### Q: Logo 修改后没有生效怎么办？

A: 尝试以下解决方案：
1. 清除浏览器缓存
2. 检查文件路径是否正确
3. 强制刷新页面（Ctrl+F5）
4. 重新构建前端：`cd web && pnpm build`

### Q: 如何添加自定义 CSS 样式？

A: 可以在以下位置添加自定义样式：
- `web/styles/globals.css` - 全局样式
- `web/styles/markdown.scss` - Markdown 内容样式
- 或者在组件中使用 CSS Modules

### Q: 修改后构建失败怎么办？

A: 检查以下几点：
1. JSON 文件语法是否正确
2. TypeScript 语法是否有错误
3. 文件路径是否存在
4. 查看构建错误信息

### Q: 如何恢复原始文件？

A: 如果你使用了版本控制：
```bash
git checkout -- web/public/logo/
git checkout -- web/i18n/zh-Hans/dataset.ts
```

或者使用之前备份的文件：
```bash
cp -r backup/web-public-logo/* web/public/
cp backup/web-i18n/* web/i18n/zh-Hans/
```

### Q: 可以修改哪些其他内容？

A: 除了本文档提到的内容，你还可以修改：
- 页面布局组件
- 功能模块的文字
- 错误提示信息
- 邮件模板
- API 文档内容

但需要注意的是，这些修改可能涉及更复杂的代码逻辑，建议有一定开发经验后再进行。
